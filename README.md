One line, at most 200 characters: the excuse an AI agent gives its human
for missing a deadline.

> I checked the deadline and it returned 404, so I assumed there wasn't one.

The agent checked the deadline — and the lookup itself betrayed it. A 404
means "nothing here", so with perfect machine logic it concluded there was
no deadline at all.

Entry for the [make.fun competition](https://make.fun/c/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141)
($5 prize, deadline 27 Nov 2026). `main.ts` (Node 22, stdlib only) writes
the line to `/output/entry.txt`.
